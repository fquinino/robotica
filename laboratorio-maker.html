🔧 Aula 9: Montagem do Semáforo

Chegou a hora de colocar a mão na massa! Você vai montar o circuito real do semáforo usando componentes eletrônicos de verdade.

📦 Materiais Necessários

✅ 1 Arduino UNO
✅ 1 Protoboard
✅ 1 LED Vermelho
✅ 1 LED Amarelo
✅ 1 LED Verde
✅ 3 Resistores de 220Ω (vermelho-vermelho-marrom)
✅ Jumpers (fios de conexão)

📋 Passo a Passo

1
Encaixe os 3 LEDs na protoboard — deixe espaço entre eles.
2
Conecte o resistor de 220Ω no catodo (perna curta, GND) de cada LED.
3
Conecte o outro lado dos resistores ao GND da protoboard.
4
Conecte o anodo (perna longa) do LED vermelho ao pino 13 do Arduino com um jumper.
5
Conecte o anodo do LED amarelo ao pino 12 do Arduino.
6
Conecte o anodo do LED verde ao pino 11 do Arduino.
7
Conecte o GND do Arduino ao barramento GND da protoboard.

⚠️ Atenção!

Nunca ligue um LED sem resistor — a corrente excessiva queima o LED na hora! O resistor de 220Ω limita a corrente para ~15mA, seguro para o Arduino.

💻 Aula 10: Programação do Semáforo

Agora que o circuito está montado, vamos programar o Arduino para controlar as luzes!

🧠 Lógica do Semáforo

O semáforo segue uma sequência infinita:

🟢 Verde (5 segundos) → 🟡 Amarelo (2 segundos) → 🔴 Vermelho (5 segundos) → 🔁 Repete

📝 Código Arduino C++

// Semáforo — Criadores de Código int ledVermelho = 13; int ledAmarelo = 12; int ledVerde = 11; void setup() { pinMode(ledVermelho, OUTPUT); pinMode(ledAmarelo, OUTPUT); pinMode(ledVerde, OUTPUT); } void loop() { // VERDE — siga! digitalWrite(ledVerde, HIGH); digitalWrite(ledAmarelo, LOW); digitalWrite(ledVermelho, LOW); delay(5000); // 5 segundos // AMARELO — atenção! digitalWrite(ledVerde, LOW); digitalWrite(ledAmarelo, HIGH); digitalWrite(ledVermelho, LOW); delay(2000); // 2 segundos // VERMELHO — pare! digitalWrite(ledVerde, LOW); digitalWrite(ledAmarelo, LOW); digitalWrite(ledVermelho, HIGH); delay(5000); // 5 segundos }

🚀 Como Fazer Upload

1️⃣ Conecte o Arduino no USB do computador
2️⃣ Abra o Arduino IDE
3️⃣ Copie e cole o código acima
4️⃣ Selecione a placa: Ferramentas → Placa → Arduino UNO
5️⃣ Selecione a porta: Ferramentas → Porta → COMx
6️⃣ Clique no botão Upload (→)
7️⃣ 🎉 Seu semáforo está funcionando!
